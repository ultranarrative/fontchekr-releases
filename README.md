# FontChekr

**Every font you own, side by side.** Browse the fonts on your Mac, sort them into collections, compare them side by side, explore every character and play with variable axes.

Free, for any Mac, Apple silicon or Intel, macOS 15.2 or later. This repository holds the installer only. More free apps at [ultranarrative.com/tools](https://www.ultranarrative.com/tools).

## Download

[FontChekr-mac-universal.dmg](https://github.com/ultranarrative/fontchekr-releases/releases/latest/download/FontChekr-mac-universal.dmg)

This link always points to the newest version.

## Opening it the first time

I sign FontChekr myself rather than through Apple, so macOS asks once. Open the disk image, drag FontChekr to Applications and open it. When macOS stops it, go to System Settings, then Privacy & Security, and click Open Anyway.
